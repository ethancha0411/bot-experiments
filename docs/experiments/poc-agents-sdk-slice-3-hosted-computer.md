# Slice 3: hosted computer

The hosted experiment inherited the provider desktop and restricted browser
network rather than building another cage. Origin approval was correlated and
recorded before submission. Computer-use calls were observed without recording
screenshots as permission evidence.

The browser fixture had no mutation capability. Consequential mutation remained
available only through the owned function gate. This demonstrates composition,
not per-click mediation: browser behavior remains watch-only and unknown at the
fine-grained action level.
